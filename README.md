# Тестирование API Petstore

Проект выполнен в рамках курса "Тестирование. Проектирование тестов".

## Описание проекта

Этот проект включает набор автоматизированных тестов для API [Petstore](https://petstore.swagger.io/). Тесты написаны с использованием Python и библиотеки pytest, и охватывают основные функции API для сущностей:
- Pet (питомец)
- User (пользователи)
- Store (магазин/заказы)

MindMap на ходится в файле Petsore_MindMap.png
Отчет в файле Test_Results_Report.pdf

## Установка и запуск

1. Клонируйте репозиторий.

2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Запустите тесты:
```
python -m pytest -v
```
